# Pinterest Posting Guide — Kitchen & Kettle

## How this works

Every product now has 3 numbered pins:

| Pin # | Style | What it is |
|-------|-------|------------|
| pin-1 | Dark overlay | Main product pin — photo background, title, hook, features |
| pin-2 | Tip card | "DID YOU KNOW?" — one practical tip on a cream card |
| pin-3 | List card | "Inside this guide" — bulleted features on a cream card |

Post them in batches. Do all pin-1s in one session. Come back another day and do all pin-2s. Then all pin-3s. That way each session is the same workflow — open folder, grab the right file, paste title/description, done.

Don't post more than 5-7 in one sitting. You can break a batch across multiple days.

## Tips

- Post 5-7 pins per sitting max. Pinterest flags rapid-fire posting.
- Space batches at least a day apart.
- Save pins to relevant boards — mix it up across different boards if you have them.
- The titles and descriptions are identical across all 3 pin styles for a given product — that's intentional. You're reinforcing the same keywords with different visuals.
