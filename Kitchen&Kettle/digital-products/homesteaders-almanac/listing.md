## Description (copy-paste)
A fill-in-your-own almanac for the dates, weather, animals, harvests, failures, fixes, and small observations that become a household's history.

This is a record of a place, kept over time. Write in it once a week or once a season — first frost, when the swallows returned, when the first tomato ripened, the year the well pump failed, or the winter the hens stopped laying for six weeks. Ten years from now, you will have a book of your own history: when things happened, what worked, and what the weather did.

**Inside (11 pages):**
- A year-at-a-glance opening page for dates, weather, harvests, and signs of the year
- An optional sky page for sun and moon observations: solstices, equinoxes, light, moonrise, and what was happening under that sky
- Four seasonal pages with room for what happened, what worked, what you would change, and the small things worth keeping
- A year-end reflection page
- A ten-year index for the longer story
- Blank, flexible prompts that work for a farm, garden, rural home, or any place you want to pay attention to

**Interactive features:** Type directly into the HTML version and your entries save automatically in your browser. Save a backup copy, import it later, or print blank pages to write by hand. Clearing browser data clears local entries, so use “Save a copy” when you want a portable backup.

This is a keepsake record, not a daily productivity system. There is no required pace and no correct way to fill it out.

▶ This is a digital download. No physical product will be shipped.
▶ To open: double-click the HTML file to open in your browser. If that doesn't work, drag and drop the file into any open browser window (Chrome, Safari, Firefox, Edge). No special software needed.
▶ For a clean printout, uncheck "Headers and footers" in your browser's print dialog before printing or saving as PDF.
▶ To print: File → Print. Use letter-size paper (8.5×11"), 100% scale. Cardstock recommended for the cover or divider pages.
▶ To save as PDF: File → Print → Save as PDF (built into every browser).
▶ Works with GoodNotes, Notability, and any PDF app.
