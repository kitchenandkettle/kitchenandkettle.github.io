# Experiments

Small tests only. Each experiment should be possible to finish in one or two sessions.

## Experiment template

- Question this tests
- Format
- Subject
- What I need to research
- What I need to make
- What was enjoyable
- What felt like work
- What I would change
- Did this suggest a second experiment?

## Suggested first test

Create three pieces on one narrow subject:

1. One evidence-based historical note
2. One modern hands-on experiment or observation
3. One personal reflection about what belongs, or does not belong, in modern life

Do not publish them yet. Make them first and see whether the process has energy.
